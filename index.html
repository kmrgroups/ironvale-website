How to get a Resend API key
  1. Go to resend.com and sign up — it is free for this volume.
  2. Left menu → API Keys → Create API Key. Give it any name.
  3. Copy the key immediately — it starts re_ and is shown only once.
  4. Paste it below and press Save.
How to send from your own domain
  1. Resend → Domains → Add Domain → type your company domain.
  2. Resend shows two or three DNS records. Copy each with the copy icon — never retype them.
  3. Add them where your domain is managed (GoDaddy, Namecheap, Vercel…). Type, Name and Value must match exactly.
  4. Back in Resend, press Verify DNS Records. It can take up to an hour.
  5. Once it says Verified, set the sender below to an address on that domain.

Until the domain is verified, use onboarding@resend.dev — but it only delivers to the address you registered with Resend. Customers will receive nothing.

Setting this system up for another company. Follow the eight stages below in order. Allow about 45 minutes for a first-time setup, 20 once you have done it a few times. Tick each stage off as you go — your progress is remembered on this device.

2

Put the code on GitHub

  1. Go to github.com and sign in.
  2. + (top right) → New repository.
  3. Name it after the client, e.g. acme-website. Leave everything else alone. Create repository.
  4. Click uploading an existing file.
  5. Drag in index.html, package.json and the whole api folder.
  6. Commit changes.

Check: the repository should show index.html, package.json and an api folder containing eight .js files. If ai.js is loose at the top level instead of inside api, nothing will work.

3

Create the database

  1. neon.tech → sign in → New Project.
  2. Name it after the client. Any region — pick one near them.
  3. On the project page click Connect.
  4. Click Show password, then Copy snippet. Keep Connection pooling on.
  5. Paste it somewhere safe — you need it in the next stage.

Each client needs their own database. Never share one between companies — their RFQs, pricing and customer details would sit in the same tables.

Neon's free plan allows one project per account. For several clients, either use separate Neon accounts or move to their paid plan.

4

Deploy on Vercel

  1. vercel.com → sign in with GitHub.
  2. Add New → Project → find the client's repository → Import.
  3. Stop before pressing Deploy. Open Environment Variables and add these four:
NameValue
DATABASE_URLthe Neon connection string from stage 3
ADMIN_USERfirst sign-in username, e.g. admin
ADMIN_PASSa strong password — write it down
ADMIN_RECOVERY_CODEany phrase, for the Forgot Password option
  1. Press Deploy and wait for the success screen.
  2. Copy the address it gives you, e.g. acme-website.vercel.app.

These four are the only settings that must live in Vercel. Everything else is done on the client's own Setup screen.

If it deploys but shows nothing: Vercel only builds when it sees a change. Add a README on GitHub to trigger it.

5

Sign in and set up email

  1. Open the new site → click the ⚙ button → sign in with the username and password from stage 4.
  2. Go to the ⚙ Setup tab. Work down the checklist at the top.
  3. resend.com → sign up → API Keys → Create API Key → copy it.
  4. Paste it into Resend API Key → Save.
  5. Resend → Domains → Add Domain → the client's domain.
  6. Add the DNS records Resend shows, wherever the domain is managed. Use the copy icons — never retype the DKIM string.
  7. Press Verify DNS Records. Usually 15–60 minutes.
  8. Once verified, set Send emails from to an address on that domain, e.g. Acme Ltd <rfq@acme.com>, and Send RFQ alerts to to the client's inbox.
  9. Press Send myself a test email.

Do not skip domain verification. Until it is done, Resend's test sender only delivers to the account owner's own address. Customers receive nothing, while the system reports success.

6

Turn on AI (optional)

Without this, everything still works — drawing details are typed in by hand instead.

  1. console.mistral.ai → sign up → API Keys → Create new key. Free tier, phone verification, no card.
  2. Paste it into Mistral API Key on the Setup screen → Save.
  3. Press Test the AI connection.

Add a second provider as a backup — Groq is also free. The system tries them in order and falls through automatically.

Free providers read images but not PDFs. If the client receives many PDF drawings, an Anthropic key (paid, roughly 2–5 US cents per drawing) handles those and reads difficult drawings better.

7

Enter the client's real data

This is the stage that decides whether the system is useful or dangerous. Work through these tabs:

  1. Company Profile — legal name, addresses, plants, tax numbers, bank details, signatory, signature, seal.
  2. Brand — logo and colours. Documents pull the logo from here automatically.
  3. Quotation Setup — numbering format, currency, tax rate, payment and delivery terms.
  4. Cost Base — working days, shifts, downtime %, electricity tariff, factory rent and area, monthly overhead, margins.
  5. Machines — delete the examples. Add every real machine: purchase cost, life, salvage, kW, load factor, floor area, annual maintenance.
  6. Labour — each grade with real wages and statutory percentage.
  7. Materials — the grades they actually buy, with their own purchase rates.
  8. Then check Cost Base again — the calculated machine hour rates appear at the bottom. Show these to the client and get them agreed before quoting anything.

Watch the overhead line. Factory overhead is divided across the machine list. With only two or three machines entered it looks enormous and inflates every price. It settles once the full list is in.

Finally, fill in the website content — hero, capabilities, process, gallery, industries, certifications, leadership — then press Publish Changes.

8

Point their domain at the site

Do this last, once the content is right — the moment you switch, whatever is on the site is what the client's customers see.

  1. If the domain currently points at an older site, remove it from that Vercel project first — a domain can only belong to one project.
  2. Vercel → the client's project → Settings → Domains → add www.theirdomain.com, then theirdomain.com set to redirect to the www version.
  3. Vercel shows the DNS records needed — usually a CNAME on www and an A record on @. Add them where the domain is managed, replacing any existing conflicting record rather than adding a second one.
  4. Wait for Vercel to show a green tick. The security certificate is issued automatically.
  5. Setup screen → Live Site Address → their new address → Save. This is what makes the pipeline link inside alert emails work.

Expect a short interruption while the change spreads. Do it outside business hours.

To roll back: remove the domain from the new project and add it back to the old one. It returns within minutes.

9

Hand over

  1. Admin → Logins → create a staff login for their estimators — pipeline only, no settings access.
  2. Change the developer password from the one you set in stage 4.
  3. Turn on two-step verification for the developer login, with their email and WhatsApp for the code.
  4. Submit a test RFQ end to end: acknowledgement to the customer, alert to them, drawing read, cost sheet, quotation PDF.
  5. Show them: how to publish content changes, where RFQs arrive, how to edit a cost sheet, and how to approve a quotation.

Tell them plainly that AI cycle times and market price estimates are starting points to be corrected from experience, and that an estimator should check every quotation before it goes out. A confident wrong price is the one real risk in this system.

Costs to be aware of. Free tiers are per account, not per client. Neon allows one project free; Resend allows 3,000 emails a month; Vercel's hobby plan is for non-commercial use. Beyond a handful of clients, budget for paid plans on all three and pass the cost on.
