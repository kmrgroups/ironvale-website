checking…

Sends you an alert when an RFQ arrives, and sends quotations to customers.

How to get a Resend API key
  1. Go to resend.com and sign up — it is free for this volume.
  2. Left menu → API Keys → Create API Key. Give it any name.
  3. Copy the key immediately — it starts re_ and is shown only once.
  4. Paste it below and press Save.
How to send from your own domain
  1. Resend → Domains → Add Domain → type your company domain.
  2. Resend shows two or three DNS records. Copy each with the copy icon — never retype them.
  3. Add them where your domain is managed (GoDaddy, Namecheap, Vercel…). Type, Name and Value must match exactly.
  4. Back in Resend, press Verify DNS Records. It can take up to an hour.
  5. Once it says Verified, set the sender below to an address on that domain.

Until the domain is verified, use onboarding@resend.dev — but it only delivers to the address you registered with Resend. Customers will receive nothing.

3 · WhatsApp notifications

checking…

You can skip this entirely. WhatsApp already works without any setup — the buttons in the pipeline open WhatsApp with the message written out, and you press send. One tap. The section below is only for making it fully automatic, which Meta makes deliberately difficult: business verification, number registration, and approved message templates. Email notifications are automatic either way, so most companies never bother with this.

Setting up WhatsApp Business API
  1. developers.facebook.com → My Apps → Create App → type Business.
  2. On the dashboard find WhatsApp → Set up.
  3. On API Setup copy the temporary access token and the Phone number ID.
  4. Click Manage phone number list and add your own mobile as a test recipient.
  5. Paste both values below and save.

Make the token permanent: business.facebook.com → Settings → Users → System Users → Add (role Admin) → Add Assets → your app → Full control → Generate New Token with whatsapp_business_messaging and whatsapp_business_management.

The 24-hour rule: Meta only allows free-form messages to someone who messaged you in the last 24 hours. Outside that window an approved template is required — create one under WhatsApp Manager → Message Templates, then put its name below.

4 · Hosting & database

checking…

These are the only things that cannot be set from this screen — they must exist before the site can run at all. If you are reading this, they are already working.

Deploying this site for another company
  1. GitHub — create a repository, upload index.html, package.json and the api folder.
  2. Neon — neon.tech → new project → copy the connection string.
  3. Vercel — vercel.com → Add New → Project → import the repository.
  4. Before deploying, add three environment variables:
    • DATABASE_URL — the Neon connection string
    • ADMIN_USER — first sign-in username
    • ADMIN_PASS — first sign-in password
  5. Deploy, open the site, sign in, and set everything else on this screen.

Optionally add ADMIN_RECOVERY_CODE so the Forgot Password option works.
